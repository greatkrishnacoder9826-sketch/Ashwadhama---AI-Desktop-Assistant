# 🧠 Ashwadhama - AI Desktop Assistant

Ashwadhama is a Python-based AI desktop assistant built using Tkinter. The project combines multiple AI and automation features such as speech recognition, translation, OCR, sentiment analysis, and web scraping into a single desktop application.

---

## 🚀 Features

* 🎤 Speech Recognition using `speech_recognition`
* 🔊 Text-to-Speech using `pyttsx3`
* 🌐 Language Translation using `deep_translator`
* 🖼️ OCR (Image to Text) using `pytesseract`
* 😊 Sentiment Analysis using `TextBlob`
* 🔍 Google Search Integration
* 🌐 Web Scraping using `BeautifulSoup`
* 🖥️ GUI Interface using `Tkinter`
* 🎬 Movie Review Search System

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ashwadhama.git
cd ashwadhama
```

Install dependencies:

```bash
pip install pillow
pip install pyttsx3
pip install SpeechRecognition
pip install deep-translator
pip install pytesseract
pip install textblob
pip install beautifulsoup4
pip install googlesearch-python
pip install ddgs
```

---

## ▶️ Run the Project

```bash
python main.py
```
